## Resulting correction

The existing Activity UI hid the undo control after an undo receipt, although earlier undo history remained. A server-derived, history-safe “next reversible change” control now exposes the actual next undo label without exposing private history contents. Python and edge regression tests cover successive undo. Deployed verification of this correction remains pending until the next version is published.
